**About this repo**

This repository builds a bilingual (EN/RU), recruiter-first, ATS-safe résumé site.
It is authored in a single markdown source and regenerated by a pure-Python build
pipeline into a landing page, a human-readable PDF, JSON Resume, `llms.txt`,
`AGENTS.md`, `.well-known/cv.json`, `agents.json`, and other machine-readable
artifacts.

- **Frontend:** self-hosted, dependency-light, fixed light Forest theme, no
  runtime CDN, no backend, no tracking (ADR-0037).
- **Identity:** neutral self-hosted pixel `AK` monogram favicon and a 1200×630
  social-preview card (ADR-0034).
- **Quality gates:** automated WCAG AA contrast checks, no-JS rendering tests,
  PDF text-layer extraction checks, cross-output consistency validation, and a
  post-deploy public smoke test.
- **Open to:** remote across European time zones or hybrid roles in Belgrade.

For contributor and build details see [`BUILD.md`](BUILD.md). For architecture
decisions see [`docs/adr/`](docs/adr/README.md). For guidance for AI agents
working in this repo see [`AGENTS.md`](AGENTS.md).
